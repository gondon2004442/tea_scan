# Как открыть Tea Scan

## Браузер на ПК (самый надёжный способ)

```powershell
cd c:\Users\gandon2004\Downloads\tea\mobile
npm install
# Ключ для ИИ-поиска (умный поиск + фото + объяснение квиза):
copy .env.example .env   # затем впиши ANTHROPIC_API_KEY в .env
npm run preview:web
```

Дождись строки `Accepting connections at http://localhost:3000`

> Сайт теперь работает в серверном режиме Expo (`web.output: "server"`) — это нужно,
> чтобы серверные роуты `/api/search` и `/api/recommend` держали ключ Anthropic и
> ходили в веб-поиск. Без `ANTHROPIC_API_KEY` приложение откроется, но ИИ-поиск и
> объяснение квиза работать не будут (локальный каталог и квиз — работают).
>
> Для разработки с ИИ удобнее `npx expo start --web` (поднимает API-роуты сразу).

Открой **только** этот адрес: **http://localhost:3000/**

Обнови без кэша: **Ctrl+Shift+R**

Не открывай старые порты (`8081`, `8082`, `64782`) — там может быть пустая страница.

### Если белый / пустой экран

1. В папке `mobile` выполни **`npm install`** (нужны одинаковые версии `react` и `react-dom`).
2. Адрес — `http://localhost:3000/` (смотри порт в строке `Accepting connections at ...`).
3. **Ctrl+Shift+R** в браузере.
4. **F12** → **Console**: ошибка про React #527 — снова `npm install` в `mobile`.

## Телефон (Expo Go)

```powershell
cd c:\Users\gandon2004\Downloads\tea\mobile
npm start
```

1. Установи **Expo Go** (App Store / Google Play).
2. Телефон и ПК в **одной Wi‑Fi**.
3. Отсканируй **QR-код** из терминала (камера iOS или Expo Go на Android).

Если QR не подключается:

```powershell
npx expo start --tunnel
```

(медленнее, но работает через интернет)

## Что должно быть на экране

1. **My teas** — зелёный фон, список чаёв, внизу «teascan.com».
2. **Explore** — фиолетовый фон, сетка чаёв, **строка поиска** (текст + фото) вверху.
3. **Квиз** (третий пункт ✨ в переключателе) — 3–4 вопроса → подбор чаёв с объяснением ИИ.
4. **Умный поиск** — если чая нет в каталоге, подключается Sonnet (веб-поиск + фото) по технике Гунфу.
5. **Модалка** — тап на чай → название, проливы, история.
